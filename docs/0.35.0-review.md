# RustWTM 0.35.0 release scope and validation

## Scope

A review release. Every page was gone over visually (English and Turkish,
light and dark, wide and compact) and functionally (each control traced to
what it does), and what came out of it was fixed. IPC is unchanged at
protocol 17 (`crates/wtm-ipc` has no change since 0.34.0), so a 0.34.0
service and a 0.35.0 GUI work together. No feature was added.

- Settings no longer rewrite config.toml when they are only opened.
  Number fields used to pull hand-set values into their range (a
  `history_days` of 730 became 365) and sliders rounded them, on the first
  frame and without input. Shown values are now left alone until the user
  changes them; the governor's two thresholds are linked so they cannot
  cross and lock the form. Kill list, Limits and the rule editor do the
  same, so editing a 2-core limit before the first sample no longer saves
  it as 1 core.
- Config saves carry the text they were made from. Before writing, the
  GUI reads the service's config again and refuses the save if it differs,
  with a message, and the page reloads. Two quick removals in the kill
  list, or an edit made to the file meanwhile, no longer undo each other.
  This uses the existing `GetConfig` and `SetConfig` requests, so the
  protocol is unchanged.
- Removing a kill-list entry, limit or rule from a config.toml that writes
  them as an inline array now says it cannot, instead of reporting a
  removal that did not happen. Renaming a limit onto another app's limit,
  or editing one removed meanwhile, is refused.
- Numbers use the language's decimal sign: Turkish, German, French,
  Spanish, Italian, Dutch, Polish, Portuguese, Russian, Ukrainian,
  Indonesian and Vietnamese write 12,5 and 8,0 GiB, and number fields
  accept either sign. The language is looked up per thread, as the
  translations are. Copied diagnostics, logs, config.toml and the service
  keep the point.
- A wait-chain analysis that could not run (no free walk slot) read
  "0 threads, 0 blocked"; the report now says it is busy, or that its
  counts are partial. The report is read by the GUI itself and never
  crosses IPC.
- Restart Windows Explorer is offered only on the Explorer that shows this
  desktop, the one it restarts. Changing tray start while administrator
  startup was set no longer restarts a window that is not elevated and
  drops the change.
- The CPU frequency and fan-control confirmations check again before
  applying; an update already found stays offered when a later check
  fails offline; the Network tab reads RustWTM's firewall rules again each
  minute and shows a read error.
- Smaller fixes: Find hits load the process; Ports sorts addresses; the
  inspector's filters belong to their process; App history and incidents
  no longer show another period; a disk's NVMe temperature reads "°C";
  and the visual changes listed in the changelog.

## Verification

`cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`,
`cargo doc` with warnings denied and the 1085 workspace tests pass on the
developer host; `scripts/ci/verify-release.ps1 -Tag v0.35.0` passes.
The fixes are tested through kittest, a stand-in service or a seam, for
example:

- Opening Service settings with out-of-range and fractional values, or
  showing a limit before the first sample, changes nothing.
- A second save is built from the reloaded text, and a save whose base
  differs from the service's text is refused without writing.
- A budget typed with a decimal comma in Turkish is read as 2.5 cores.
- The wait-chain walker's slot limit is passed in, so "no free slot" is
  proven without starting any walks; nothing exhausts host resources.
- The Explorer check uses a stand-in for the desktop's Explorer PID.

The release review renders pass in English, Turkish, German, French and
Spanish at 1x and in Turkish at 1.5x. Of this version's renders, English,
Turkish and German pages were spot-checked (About, Processes at 1.5x,
Ports, Installed apps, Hardware specifications, the compact timeline and
Kill list, and Ports compact in all five languages); versions, addresses and BIOS revisions keep the point while
sizes and speeds take the comma. The pages were reviewed in English and
Turkish during the visual review before the last fixes. The screenshots
in `screenshots/` are rendered again from them for this version. Hosted
Windows CI adds 0.34.0 as an upgrade baseline, with the checksum of its
published MSI.

Not verified against the installed service: the refused save. It is
tested over a named pipe against a stand-in service that answers
`GetConfig` and `SetConfig` with the real protocol.

Known: `shows_drives_activity_and_who_writes` failed once in a parallel
run before this release. The folder check ran after the Analyze/Stop row
was drawn, so for one frame Stop stood beside the error; the check now
runs first.

Left as they are: the Overview Network card opens the first adapter;
Ports' listening-ports table scrolls sideways on a narrow window (its
actions are also on the row's menu), as do wide process tables.
