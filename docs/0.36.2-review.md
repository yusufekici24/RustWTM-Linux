# RustWTM 0.36.2 release scope and validation

## Scope

A fix release from the visual review of the pages 0.36.0 and 0.36.1 had
not looked at. IPC is unchanged at protocol 18 (`crates/wtm-ipc` has no
change since 0.36.0), so a 0.36.x service and a 0.36.2 window work
together.

- The process inspector's up time is written in the window's units, and
  lengths of two days or more are written in days and hours ("6 gün
  23 sa"). A single day stays in hours ("30 sa"): the catalog's day unit
  is a plural, and Ukrainian's is now the abbreviation "дн.".
- Sensors' *Min / max* column uses the language's decimal sign.
- English names priority classes in words ("below normal") where the
  service's text gives Windows' name ("BelowNormal"): the Governor's
  effective limits and its events.
- Limits writes memory budgets in GiB, which is how the service applies
  them (`memory_gb` × 2³⁰); so does `wtm config`.
- The Kill list's CPU field places the percent sign as the language does
  ("%50 CPU"); Network writes "TCP" and "UDP".
- Catalog: the singular forms of five counted phrases had been given the
  plural in German, French, Spanish, Italian, Dutch, Brazilian Portuguese
  and Ukrainian. Turkish percentages no longer take a suffix that fits
  only some numbers, "instance" is "kopya", and a number of Turkish and
  German phrases are reworded. The unused keys " GB", "{0} GB" and
  "% CPU" are removed from all 26 languages.

## Verification

`cargo fmt --check`, `cargo clippy --workspace --all-targets -D warnings`,
`cargo doc` with warnings denied and the 1169 workspace tests (22
ignored) pass on the developer host; `scripts/ci/verify-release.ps1
-Tag v0.36.2` passes. New tests check the Turkish inspector up time,
sensor ranges in Turkish, English priority names and the day unit. CI adds
0.36.1 as an upgrade baseline, with the SHA-256 of its published MSI (the
release asset's digest and its `.sha256` file agree).

Reviewed visually in English, Turkish and German, light and dark, wide and
compact: Processes (selection, inspector, column editor, memory profile),
Disks (activity, file types, largest files), Sensors, Hardware, Installed
apps (selection, confirmation), Governor, Limits, Kill list, Services,
Startup, Users, Network, Ports, App history and the System workspace.
Processes, Sensors, Governor, Limits, Kill list, Network, Ports, Startup,
App history and Installed apps were rendered again after the fix.

Seen and left as they are:

- On a compact window the status bar wraps its message to a second line,
  and the *More below* marker can cover the last row or button it points
  past.
- Wide tables that scroll sideways cut their last column without an
  ellipsis (App history's *Finding*, Installed apps' *Estimated size* in
  German).
- German writes "37 %" on Disks and "90%" elsewhere.
- Large file counts on Disks are not grouped ("1204311 files").
- The inspector's CPU row shows two decimals ("12.40%") where the header
  shows one.
- The singular forms in the Indic and Swahili catalogs were not checked.
